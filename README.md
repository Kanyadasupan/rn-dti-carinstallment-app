# 🚗 Car Installment App
### Calculate your car payments easily and accurately 📊
**Mobile Application developed with React Native Expo**

ยินดีต้อนรับสู่แอปพลิเคชันคำนวณค่างวดรถ (Car Installment App) ตัวช่วยที่จะทำให้การวางแผนซื้อรถของคุณเป็นเรื่องง่ายขึ้น สามารถคำนวณยอดจัด เงินดาวน์ อัตราดอกเบี้ย และค่างวดรายเดือนได้อย่างรวดเร็วและแม่นยำ

---

## ✨ คุณสมบัติหลัก (Features)
* **💵 Payment Calculation:** คำนวณค่างวดรถรายเดือนได้อย่างรวดเร็วและแม่นยำ
* **📊 Adjustable Parameters:** สามารถปรับเปลี่ยนราคารถ เงินดาวน์ อัตราดอกเบี้ย และระยะเวลาการผ่อนชำระได้ตามต้องการ
* **🎨 Clean & Modern UI:** อินเทอร์เฟซที่ใช้งานง่าย สะอาดตา และเน้นประสบการณ์ที่ดีของผู้ใช้
* **📱 Responsive Design:** รองรับการทำงานอย่างสมบูรณ์แบบบนสมาร์ทโฟนทุกขนาด ทั้งระบบ iOS และ Android

## 🚀 การติดตั้งและใช้งาน (Setup & Installation)

1.  **Clone โปรเจกต์:**
    ```bash
    git clone [https://github.com/KanyadaSupan/car-installment-app.git](https://github.com/KanyadaSupan/car-installment-app.git)
    cd car-installment-app
    ```
    *(อย่าลืมตรวจสอบและเปลี่ยน URL ของ Repository ให้ตรงกับของคุณด้วยนะครับ)*

2.  **ติดตั้ง Dependencies:**
    ```bash
    npm install
    ```

3.  **รันแอปพลิเคชัน:**
    ```bash
    npx expo start
    ```
    *จากนั้นสแกน **QR Code** ผ่านแอป **Expo Go** บนมือถือของคุณ (iOS/Android)*
